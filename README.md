# CRUD Application – Person Management System

A full-stack CRUD application designed to manage person records efficiently. The application allows users to add, view, update, delete, and search person information through a simple and responsive web interface.

# Features

- Add new person records
- View all person records
- Edit person details
- Delete person records
- Search people by name or details
- Display total number of people
- Display people added today
- Gender selection
- Course / Role information
- Form validation
- Responsive user interface
- REST API integration
- SQL Server database

# Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- CORS

### Database
- Microsoft SQL Server
- MSSQL
- msnodesqlv8
